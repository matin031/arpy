# موتور عروض فارسی — نسخهٔ ۱۳

تشخیصِ وزن و تقطیعِ عروضیِ شعر فارسی. ۱۷۸ وزنِ گنجور + اختیاراتِ شاعری.

## فایل‌ها
| فایل | کار |
|---|---|
| `arooz.py` | موتور |
| `run.py` | تستِ بیت‌های خودت — **این را اجرا کن** |
| `bootstrap_lexicon.py` | ★ ساختِ واژه‌نامه (قدمِ بعدی — مهم‌ترین) |
| `build_lexicon.py` | نسخهٔ جایگزین (با پیکرهٔ برچسب‌خوردهٔ P3R) |
| `lexicon.json` | واژه‌نامه (اختیاری) |

## اجرا
```bash
pip install numpy
python run.py
```
چند بیت را با هم بگذار:
```python
ABYAT = [
    ("مصراع اول", "مصراع دوم"),
    ("مصراع اول", "مصراع دوم"),
]
```
یا شعرِ کامل (دقتِ خیلی بیشتر) در `SHER`.

## ★ قدمِ بعدی: واژه‌نامه — این سقف را می‌شکند

**مشکلِ ریشه‌ای:** موتور نمی‌داند واژه در شعرِ کلاسیک چه وزنی می‌گیرد، پس برای
هر مصراع هزاران خوانش می‌سازد و وزنِ غلط هم تصادفاً «تطبیقِ کامل» پیدا می‌کند.
هرچه ضریبِ دستی کوک کنم، یکی درست و دیگری خراب می‌شود. راهِ خروج: **داده.**

**ایده:** یک شعرِ کامل ده‌ها مصراعِ هم‌وزن دارد. این قید آن‌قدر قوی است که موتور
می‌تواند وزنِ شعر را با اطمینان بگیرد — حتی وقتی تک‌بیت مبهم است. بعد با
هم‌ترازیِ وزن‌مقید یاد می‌گیریم هر واژه **در عمل** چه وزنی می‌گیرد:

| واژه | وزنِ استخراج‌شده | یعنی |
|---|---|---|
| بود | `U-` | بُـوَد (نه būd) |
| و | `U` | واو عطفِ کوتاه |
| سر | `UU` | سَ‌رِ (کسرهٔ اضافه) |
| کرد | `-` | کشیدهٔ تخفیف‌یافته |

### اجرا (دو دستور)
```bash
# ۱) پیکرهٔ گنجور (۲۶۵ مگابایت، بدونِ LFS — راحت clone می‌شود)
git clone --depth 1 https://github.com/aghasemi/ChronologicalPersianPoetryDataset

# ۲) واژه‌نامه را بساز (چند ساعت؛ با --poems کمترش کن)
python bootstrap_lexicon.py ChronologicalPersianPoetryDataset/poems_with_more_info.tsv --poems 5000
```
`lexicon.json` را کنارِ `arooz.py` بگذار. موتور خودش می‌خوانَدش
(زیر ۵۰۰۰ واژه نادیده گرفته می‌شود چون نویز است).

## چه اصلاح شد (۱۴ باگِ واقعی)
واو عطف (کوتاه و چسبان) · کسرهٔ اضافهٔ نانوشته (کوتاه و بلند) · واو معدوله ·
حذفِ ع · قاعدهٔ «ن» پس از مصوت بلند · وصل/همزهٔ اختیاری · تخفیفِ هجای کشیده ·
**هجای پایانیِ مصراع = همیشه یک هجای بلند** · کوتاه شدنِ مصوتِ بلند ·
ادغامِ «است» (بوده است → بودست) · ۲۴ گونهٔ وزنِ رباعی ·
اختیاراتِ وزنی (ابدال، قلب، فاعلاتن/فعلاتن) · آغازهٔ اجباری · هزینهٔ نامتقارن
